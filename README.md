## 🚀 Cara Menjalankan & Membuka di Komputer Sendiri

Kamu bisa langsung membuka file `index.html` dengan klik dua kali di browser (Google Chrome, Edge, Safari, dll.).

Atau menggunakan server lokal ringan:
```bash
python -m http.server 8080
```
Lalu buka di browser: `http://localhost:8080`

## 🌐 Cara Deploy Gratis ke Internet (Agar Bisa Discan via QR Code)

Agar Mahira bisa membuka website ini dari HP-nya saat scan QR Code di kado, unggah proyek ini ke internet secara gratis dengan salah satu cara berikut:

### Opsi 1: Menggunakan Vercel (Paling Cepat & Populer, < 2 Menit)
1. Buka [vercel.com](https://vercel.com) dan masuk dengan akun GitHub / Email.
2. Tarik (*drag and drop*) folder `PROJECT 26TH` ke dashboard Vercel.
3. Website akan langsung aktif dengan domain HTTPS gratis (misal: `a-month-with-mahira.vercel.app`).

### Opsi 2: Menggunakan Netlify Drop (Tanpa Koding/Akun Ribet)
1. Buka [app.netlify.com/drop](https://app.netlify.com/drop).
2. Seret (*drag and drop*) folder `PROJECT 26TH` ke kotak yang tersedia.
3. Selesai! Kamu akan langsung mendapatkan link aktif.

---

## 🖨️ Cara Cetak QR Code untuk Kartu Kado

1. Buka file `qr-card.html` di browser.
2. Masukkan link website yang sudah kamu dapatkan dari Vercel/Netlify.
3. Klik tombol **"Cetak Kartu 🖨️"** (bisa disimpan sebagai PDF atau langsung dicetak ke printer).
4. Tempelkan kartu QR Code ini di kartu ucapan, buket bunga fisik, atau kotak kado Mahira!
